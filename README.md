# HARP

Hardware designs, ROS 2 mapping tools, and dynamic programming (DP) route planning
for a modular rover-drone system.

| Folder | Contents |
| --- | --- |
| [CAD/](CAD/README.md) | Rover and drilling payload designs, assembly inventories, and images. |
| [mapping/](mapping/ros2_ws/src/) | ROS 2 workspace for mapping, exploration, and map export/editing. |
| [path_planner/](path_planner/README.md) | Air/ground DP planner, input maps, configuration, and tests. Main scripts are in `path_planner/script/`. |

Start with the [CAD guide](CAD/README.md),
[mapping and map editor guide](mapping/ros2_ws/src/mod_explore/MAP_EDITOR.md), or
[DP planner setup and examples](path_planner/README.md).
